# 🗳️ Online Voting System

A simple and responsive **Online Voting System** built using **HTML, CSS, and JavaScript**. This project demonstrates JavaScript DOM manipulation, event handling, and dynamic data updating by allowing users to cast votes and view final voting results.

## 🚀 Features

- ✅ Cast votes for different parties
- ✅ Dynamic vote counting
- ✅ Display final election results
- ✅ Total votes calculation
- ✅ Responsive design for desktop and mobile
- ✅ Modern and interactive user interface
- ✅ Built using JavaScript DOM manipulation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation

## ⚙️ How It Works

1. Users select a party by clicking the vote button.
2. JavaScript captures the button click using event listeners.
3. The vote counter increases for the selected party.
4. Users can view the final result by clicking the **Show Result** button.
5. The application displays:
   - Individual party votes
   - Total votes cast
